# Dynamic-Skyline-Queries-with-Updates
You are given a set of buildings in a city, each represented by (x, height). A building at position x has a height height.

You need to support two types of operations efficiently:

Update: Change the height of a building at position x.

Query: Given a range [L, R], return the skyline profile — i.e., the maximum height among buildings in that range.

Constraints:

1≤𝑁,𝑄≤10^5

Heights can be up to 
10^9.

Operations must be efficient (logarithmic preferred).
